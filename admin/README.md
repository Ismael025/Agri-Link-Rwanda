# Agri-Link Independent Admin Portal

Open `pages/admin-dashboard.html` with Live Server.

Every page has one matching independent HTML, CSS and JavaScript file. No shared CSS or JavaScript is required. All SVG icons are stored locally in `icons/` and the project has no external asset dependency.

The portal is a frontend prototype. Demonstration records and UI actions are prepared for later backend, authentication, database, payment and delivery integrations. Administrator accounts must be created privately by an authorized administrator; they are not part of public registration.
